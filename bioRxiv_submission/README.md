# bioRxiv 预印本投稿 —— 操作说明 (README)

## 文件夹结构

```
bioRxiv_submission/
├── README.md                            ← 本文件
├── main_manuscript.docx                 ← 主稿件（含内嵌图片和表格）
├── cover_letter_biorxiv.md              ← bioRxiv 投稿信
├── main_figures/                        ← 主图 Fig 1-7（22张PNG，300dpi）
├── supplementary_figures/               ← 补充图 Fig S1-S9（9张PNG）
├── supplementary_tables/                ← 补充表 Table S1-S13（13张CSV）
├── supplementary_materials.docx         ← 补充材料整合文档
└── data_code_availability.md            ← 数据和代码可用性声明
```

## 投稿步骤（3步完成）

### 第1步：将主稿件导出为 PDF

1. 用 Word 打开 `main_manuscript.docx`
2. 文件 → 另存为 → PDF
3. 保存为 `main_manuscript.pdf`
4. 检查 PDF 中图片是否清晰、页码是否连续

### 第2步：注册 bioRxiv 账号

1. 访问 https://www.biorxiv.org/
2. 点击 "Submit" → 注册账号
3. 建议用 ORCID 登录（如未注册 ORCID：https://orcid.org/）

### 第3步：在线提交

1. 登录 bioRxiv → "Submit a New Preprint"
2. 上传 `main_manuscript.pdf`
3. **Subject Area**: 选择 "Neuroscience"
4. **Article Type**: "New Results"
5. **Title**: 粘贴标题（见封面信）
6. **Authors**: 填写作者信息（杨永新）
7. **Abstract**: 粘贴摘要（见稿件第2页）
8. **Author Approval**: 确认所有作者已批准
9. **Competing Interests**: "No competing interests declared"
10. **Data Availability**: 粘贴 `data_code_availability.md` 内容
11. 上传补充材料（可选）：`supplementary_materials.docx` 作为 Supplementary Material
12. 确认并提交

## 提交后

- 一般在 24-48 小时内通过筛选并在线发布
- 获得 DOI（如：`https://doi.org/10.1101/2026.05.18.XXXXXX`）
- 可在 Twitter/X、ResearchGate 等平台推广
- 建议同时提交到期刊（bioRxiv 允许并行投稿）

## 注意事项

- bioRxiv 对格式无严格限制，任何可读的 PDF 均可
- 上传前请把占位符（作者名、单位）替换为真实信息
- 建议先投 bioRxiv 再投期刊，而非同时等待
- 一旦张贴即为永久公开记录，不可撤回
